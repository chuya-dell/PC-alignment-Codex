# v70 手順A:台帳・現行標準の固定・実中心(Claude Code 単独実装。【独立批評待ち(Codex の枠切れ)】)

## 実装
- `v70_ledger.py`:既存632視野の台帳(日程・基板・視野・固定29の印・原画像の実在・split=development)。`data/results/v70_ledger_center_fit/ledger.csv`。
- `v70_lib.py`:格子当てはめ(v61 の lattice_centers を複製)、ピラー1個ずつの小数精度中心(ガウス重み付き重心、半径3画素、仮置き)、`standard_run`=現行標準(`current_standard_v70`。粗いアフィン→精緻化→理想格子ピッチ7.286→整数丸め3×3背景差分)。
- `v70_run_field.py`:全632視野で現行標準を再実行(`fields/`)。保存値(2026-09-28)との相関の中央値 ≈ 1.0、最小0.654(8視野が<0.99。原因未調査)。旧標準の再現とは書かない。
- `v70_centers2.py`:3次の滑らかな格子モデルで中心を再当てはめ、物理的な格子番号(格子から決まる線形写像 L+アフィン中心の平行移動で整数周期を決定、サブ周期は格子から)(`fields2/`)。
- `v70_summary2.py`/`v70_standard_mismatch.py`:対応率・理由・現行標準の読み取り位置誤差。
- 初版(`v70_summary.py`、アフィンで対応づけ)は比較のため残す。

## 結果(実測。詳細は Vault の【未読】手順A_*.md)
- 対応率(代用なし、主基準):中央値 86.8%、最小 64.6%(仮置き合格=中央値95%・最小85%は**未達**)。固定29:中央値89.2%、最小80.4%。緩め基準なら中央値93.2%・最小84.1%。
- 初版(アフィンで対応づけ)は中央値76.5%(v59 の74.6%と同程度)。差の主因は、アフィンと格子線形写像の食い違い。
- 現行標準の読み取り位置:理想格子(7.286)は実中心から中央値2.54画素、最大3.64画素。前後の読み取り位置の相対ずれ:中央値0.77画素(固定29は4.4画素)。
