## 実装内容

- ROI: 半径1.5 px、0.25 px刻みの双線形補間、円内平均。

- 量子化: `median(diff(unique(image)))` による画像別除算は、後続監査で物理的量子化幅ではないと判明したため適用しない。
- 標準出力: 数値JSONのみ。判定語は出力へ埋め込まない。

### 統計量の定義

視野内の有効ROIを `i=1..N`、pre/post信号を `P_i`, `Q_i` とする。

```text
D_i = Q_i - P_i
M_i = (P_i + Q_i) / 2
τ_pair[%] = 100 × SD(D_i) / mean(M_i)
τ_single_equivalent[%] = τ_pair / sqrt(2)
操作起因ブレ[%] = sqrt(τ_pair² - 装置ノイズ_pair²)
```

`τ_pair` と装置ノイズはどちらも二枚差分の同一定義であり、single-frame換算値との混在を避けている。

過去ノートの `τ_raw` と `τ_net` は標準偏差ではなく、上側0.1%の経験的閾値である。

```text
R_i = 100 × (Q_i - P_i) / P_i
τ_raw = percentile_99.9(R_i - median(R))

B = percentile_0.5(pre画像全画素)
N_i = max(100, P_i - B)
Rnet_i = 100 × (Q_i - P_i) / N_i
τ_net = percentile_99.9(Rnet_i - median(Rnet))
```

この旧指標ではpre検出ピラーの整数座標、3×3 box blur、pre輝度の下位8%除外を使う。格子全点の円形ROI差分SDである `τ_pair` とは、対象点・サンプリング・分母・統計量が一致せず、単純比較できない。

## 結果概要

- 8視野の `τ_pair`: 15.25–30.82%、平均22.10%、中央値21.12%。
- 6 ms装置ノイズ_pair: 260901が10.46%、260904が10.52%。
- 260904の6 msペアを基準にした操作起因ブレ: 11.04–28.96%、平均19.21%、中央値18.30%。
- FOV 1-6の8候補はすべて同じ変換近傍へ収束した（ρ≈0.97144、tx≈1.327 px、ty≈−2.029 px、det≈0.99522）。周期1個分ずれた別解は今回の候補群では残っていない。
- 260904ノイズ分布の固定閾値（中央値中心化後 +74.63% / −45.54%）を使ったデジタル集計では、全730,821 ROI中、正方向5,393（0.738%）、負方向22,041（3.016%）。全視野で負方向超過が正方向より多く、DNA結合由来の片側陽性差より、操作・輝度変動の非対称性が優勢である。
- 実測の操作起因ブレに9/3の理論改善係数（背景モデル、ROI拡大2倍、1000フレーム平均）を適用した3σ投影値は0.166–0.436%。これは実測検出限界ではなく理論投影値である。

## 監査上の結論

260903監査ログにはECC、warp、登録行列、ピラミッド初期化の記録がなく、31.54%の計算に使われた登録版は特定できない。ログ上は画像ごとの格子fitと局所重心処理が記載されるため、9/1のピラミッドECC修正版を使用したことは確認できない。したがって31.54%を「修正後登録の値」と扱うことはできず、登録由来の過大評価可能性を残す。

また、260903の一部計算は二枚差分の `τ_pair` からsingle-frame相当の装置ノイズを差し引いており、分散差の定義が一致していない。本スナップショットではpair同士へ統一した。
