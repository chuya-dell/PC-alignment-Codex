# 検証メモ

## 保存対象

このスナップショットは、260827 DNAのSample12対Sample11について行った視野単位比較と台帳監査のコード・小規模CSVだけを保管する。実験画像、生成画像、キャッシュ、格子点全件出力は保存しない。

## 再現コマンド

```powershell
python field_reproduce_fov_statistics.py
```

期待値:

- `rate: n=6 vs 7, U=22.0, p=0.9452214452214451`
- `delta_mean: n=6 vs 7, U=19.0, p=0.8356643356643356`

## 台帳監査上の安全条件

- Sample11位置7の除外は、一次記録のシミ記載に基づく。
- 一次記録に欠陥の記載がないことを、欠陥なしの根拠としてはならない。
- したがって、記載がないSample12視野を「欠陥なし」とラベル付けしていない。
- 解析上の採用・除外、画像の完全性、欠陥の有無は別の事実として扱う。

## 検証範囲外

この小規模再現は既に集計済みのFOV値を使う。FFT格子生成、画像位置合わせ、ICP、実験TIFFの再読込は実行しない。
