# raw QC brightness: 260910 validation snapshot

## 位置付け

共通領域のraw画素平均は、デジタルカウントの研究エンドポイントではない。格子点直接サンプリングは維持し、この値は照明・背景変動の補助QCとしてのみ扱う。

差分方向は `pre - post` で固定する。既存の格子点サンプラー内部の `post contrast - pre contrast` と符号が逆である。

## 260827での確認結果

- raw TIFFの15ペアはすべて2048 x 2044 pxでサイズ不一致はなかった。
- ただし、現行の直接サンプリングは格子点座標をpost側へ逆投影するだけで、登録・共通領域切り出し済みTIFFを出力していない。
- raw全視野平均と符号調整済み格子点結果のSpearman rhoは -0.033 (p = 0.915)。
- raw全視野のexact Mann-Whitney pは0.00218、既存格子点の視野比較pは0.8357。

よって、raw全視野平均を格子点方式と置き換えたり、直接に比較したりしない。
