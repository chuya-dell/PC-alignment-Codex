# v85 異常ピラーのマッピング(本人の依頼、2026-10-08。Claude Code 単独。【独立批評待ち】)
- 異常ピラー=後ろ側の当てはめ失敗(S5 NaN)かつ S5P 有効かつ |z|>6(4・8は感度)。傷の外=v57 マスクの2周期より外。
- `v85_prep.py`(97視野の異常ピラー表・距離・基準分布)、`v85_maps_fields.py`(視野ごとの地図と陽性比較k=4)、`v85_analysis.py`(距離別・日程基板位置・濃度)、`v85_hotspots.py`/`v85_hotspot_post.py`(カメラ固定の欠陥13か所)、`v85_hotspot_effect.py`、`v85_mask_strategies.py`(欠陥除外での部分B再評価)、`v85_repro.py`(再現性)。
- 主な発見:異常ピラーの約93%は後ろの像の座標に固定された13か所の欠陥(視野の0.48%)に由来。結果:`data/results/v85_abnormal_pillars/`。画像:ノート置き場の `図と表/`。
- 既知の問題:欠陥は開発用の非ブランク視野で決めた(今日のデータで独立に確認)。傷マスクは自動(目視承認前)。
