# v77 手順G:信号注入(Claude Code 単独。【独立批評待ち】)
- `v77_inject.py`:洗浄後の生画像に、位置合わせ前に既知のガウス像(σ=1.3画素)を足す。強さ=視野の差分の頑健SD×{3,5,10}、増光・減光、場所=中心/端/傷の外(2〜6周期)、孤立(24)/集積(7個×4)。全工程(位置合わせ・実中心・各読み取り S0..S5、P方式)を通して回収率と測光の偏りを測る。試験の種類:実ブランク6視野(実変位+注入)、連写(輝度のみ)、連写+既知の1/4画素ずらし。
- 結果:`data/results/v77_signal_injection_P2/`。初版(P方式なし)は設計の欠陥(後ろ側の当てはめ失敗で強く暗くなったピラーを除外)を示し、P方式を追加。
- 注意:10σの減光は、ピラー自身のコントラスト(視野により0.08〜0.19)の約2〜3倍(σ≈0.03〜0.04)で物理的に非現実的。3σは約60〜120%の変化(以前の「約25〜30%」は誤り)。回収率≈0%は、注入の最大強度10σ<凍結閾値10.5σの設計上の天井(独立批評)。`--amps 15,20,30,40` で検出下限を出す追加実験(出力 data/results/v77_signal_injection_P3_high)。
