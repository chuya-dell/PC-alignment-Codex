# v49 semi-synthetic local correction

## Pre-registered protocol (fixed before execution, 2026-10-06)

- **Question.** Measure known local-deformation recovery at pillar centres, compare the current standard affine configuration with local candidates under identical semi-synthetic conditions, report per-FOV median and 95th-percentile truth error, and count improvements/worsening using a fixed 0.002 px median-error tolerance.
- **Input framework.** The immutable v11 `baseline_inputs.json` ledger (452 affine conditions from 27 images; v5/v17 lineage) supplies source images and affine truth. Paths are translated only by replacing the verified legacy data-root prefix with the locally enumerated W: root. The source images are read only. Centres are detected once per source using v17's independent FFT-grid/top-hat/parabolic detector. This is a coordinate-level extension of the semi-synthetic framework: local truth, matching observations, and detector-like noise are generated after the established affine condition; no production registration default is touched.
- **True field.** Seed `20261006`. For every condition, a deterministic smooth vector field is formed from two sinusoidal directions with independent phase/signs, rotated orientation in `{vertical, diagonal, irregular}`; both components are separately normalised over evaluated pillars to RMS in `{0, 0.1, 0.3, 0.415, 0.6}` px. Wavelengths are `{W/8,W/4,W/2}` where W is the geometric mean of image width/height. `irregular` is a deterministic two-mode non-axis-aligned field. A fixed affine-like standard residual is independently seeded and calibrated to a per-FOV median magnitude of 0.004 px. Observation noise has per-component Gaussian SD 0 (clean) or 0.46 px (the requested real-data-like independent component); it is used only for fitting/validation, never for truth evaluation.
- **Validation.** Pillars are assigned once per condition to deterministic 80/20 checkerboard-like hash split (training/validation) from integer-rounded coordinates and seed. Candidate/hyperparameter selection minimises validation median Euclidean residual after fitting only training pillars. The known local truth is inaccessible to selection and used only for reported error.
- **Candidates and fixed search.** (1) blockwise affine, grids 2x2, 4x4, 6x6; (2) thin-plate spline (`scipy.interpolate.RBFInterpolator`, thin-plate-spline kernel), smoothing {0.01, 0.1, 1.0}; (3) smooth displacement polynomial ridge, degrees {2,3}, ridge {1e-4,1e-2,1}. Block affinity uses affine regression in each block with global affine fallback for insufficient support. The selected candidate is refit on all observed pillars, with no re-selection.
- **Metrics.** For every method/condition/FOV: the median and p95 of Euclidean error between corrected coordinates and known truth; all-FOV median and bootstrap-free quantiles. Relative to standard: improved if median difference <= -0.002 px, worsened if >= +0.002 px, otherwise unchanged. Required tables stratify amplitude/scale. Representative plots show true displacement, standard remainder, selected-candidate remainder; comparison plots use condition means.
- **Staging.** Stage A verifies all 452 zero-local-deformation affine conditions. Stage B runs a balanced 27-source probe (one ledger case/source) across the full deformation grid; this makes the local-model comparison computationally bounded and is explicitly labelled as a probe rather than an all-452 expansion. A full 452 x grid expansion is deliberately not silently substituted for Stage B.
