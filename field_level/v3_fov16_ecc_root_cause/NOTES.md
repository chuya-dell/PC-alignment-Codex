# v3 FOV 1-6 ECC root-cause diagnosis

## 実装内容

Phase 2用の視野レベル診断。既存 `shared.analyzer` のサブピクセル局所極大検出と、
`shared.lattice_indexing` のFFT格子方位を再利用する。ECCは現行リポジトリに既存実装が
なかったため、この診断バージョンに限定してOpenCV ECCを実装する。既存の登録処理や
確定ピッチ `a=7.286 px` を変更しない。

FOV 1-6は0.125→0.25→0.5→1.0の4段ピラミッドを、初期並進−10〜+10 px（5 px刻み）
の25通りで走査する。FOV 1-1、1-5は検出品質・FFT方位・焦点の比較対象とする。

## 結果概要

実行済み。4段・25初期値の全経路は `rho=0.986602–0.986606` の同一解へ収束し、
標準3段ゼロ開始も同値だった。深い初期化は既存経路の置換根拠にならない。詳細は
`docs/FOV16_ECC_ROOT_CAUSE_PHASE2_REPORT_20260916.md` を参照。

## 既知の問題

ECCは画像強度パターンに基づく独立診断であり、既存ICP登録の置換ではない。深い初期化で
ρ≥0.978が再現可能に得られた場合だけ、既存パイプラインへの適用を別途判断する。
