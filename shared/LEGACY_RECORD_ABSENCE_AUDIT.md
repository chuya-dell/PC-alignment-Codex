# 一次記録の未記載をクリーン扱いしていた旧処理の監査

一次記録に欠陥の記載がないことは、欠陥なしの証拠ではない。このため、以下は現在のピクセルマスク解析の入力として使わない。

| 場所 | 旧挙動 | 対応 |
|---|---|---|
| `qc_filter_v2.py:get_l3_mask` | 座標CSVに該当行がなければ全格子点を有効のまま返した。さらに `(0,0)` プレースホルダーを視野全体除外として扱った。 | 未完了レビューでは例外に変更し、プレースホルダーはピクセルマスクとして拒否する。 |
| `crossday_p50_260907/run_crossday_direct_sampling.py` | ハードコードされた `CLEAN_POSITIONS` を、一次記録由来の視野採用リストとして用いた。 | 260907の再現用・過去結果用として残す。新しい実行経路では使用しない。 |
| `crossday_p50_260907/crossday_manifest_used.json` と監査文書 | 一次記録を根拠に「クリーン」と表現した。 | 歴史的な視野全体除外方式の記録であり、未記載をクリーン判定する根拠として再利用しない。 |
| `defect_coordinates.csv` | 一次記録を `(0,0)` の座標なし行へ転記した。 | 座標付き承認マスクではない。新しい実行経路は読まない。 |

新しい `target_manifest.json` の `legacy_included` は比較レポートの「適用前」母数を再現するためだけの名称であり、欠陥なしの意味を持たない。候補生成は全対象視野のpre/post画像に対し、一次記録の有無とは独立に行う。
