# v2_hex_group7 — 暫定7個組集約

## 実装内容・旧版からの変更点

- requirements/requirements.md v1 の R-01〜R-04 に対応する独立後処理。
  既存の個別解析、shared、旧バージョン、要件書は変更しない。
- **本人未確認の暫定解釈**: 各ピラーを中心に最近接6個を加える。
  周辺ピラーの共有を許容する。実装前に会話で要約し、テスト冒頭・実行ログ・出力列にも明記。
- 入力は既存個別解析の **1視野分** の結果表。`x`, `y` と選択した数値指標を使用。
  `shared/theoretical_grid_evaluation.py` の `sample_grid_features` 出力
  (`ints`, `contrast`, `centre_intensity` など) をそのまま利用できる。
  複数視野や異なる撮影時点を混ぜず、視野ごとに実行する。
- 既知のピッチを明示指定する。座標と同じ単位で距離を計算し、ピッチの±15%を
  最近接殻として採用する（変更可能、許容値は0以上0.3未満）。
  六方格子の第2殻は理想的にはピッチの√3倍であり、欠損を第2殻で埋めない。
  近傍が6個で、角度順の隣接間隔が40〜80度の中心のみを採用する。
  格子端・穴・余分な近接点などで条件を満たさない中心は **除外** する。
- 各指標の平均・母標準偏差（自由度補正0）を計算。
  欠損値・無限大・既存 `valid_sampling=False` が含まれる指標は平均・標準偏差を
  欠損値にし、有効数を記録する。7個未満の平均へ黙って置き換えない。
  マスクの承認・欠陥判定は行わない。入力の適格性確認は既存の上流処理で行う。
- 出力には中心、7個のメンバー、入力行位置（0始まり）、指標統計、暫定状態、
  ピッチ・許容幅・自由度補正を記録する。識別子列未指定時は入力行位置を識別子にする。
  メンバーは中心が先頭、その後は画像座標上の角度順。識別子配列は文字列として保存する。
- 出力先はこのクローンの `data/results/` 配下のみ。同一入力パスおよび
  既存ファイルへの上書きを拒否する。個別解析結果を変更する処理はない。

### 実行例

既存の1視野結果が `data/results/individual/field.csv` にある場合:

```powershell
python pillar_level/v2_hex_group7/pillar_hex_group7.py data/results/individual/field.csv data/results/hex_group7/field_groups.csv --pitch 7.286 --metrics ints contrast centre_intensity
```

ピッチは入力を生成した格子に合わせる。`7.286` は例であり強制しない。
列名が異なる場合は `--x`, `--y`, `--id-column`, `--valid-column` を指定する。
入力ファイルは加工せず読み込み、出力は毎回新しいファイル名を指定する。
空の入力・完全グループがない場合も列名付きの空の結果表を出す。
