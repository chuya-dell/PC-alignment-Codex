# 既知の位置ずれがピラー測光値と濃度比較へ与える影響（B段階）

実施日: 2026-09-28

## 評価の目的と手順

現行の本番統計処理を保ったまま、位置合わせ後の洗浄後画像の標本座標へ既知の平行移動を加えた。前画像の高速フーリエ変換から理論格子を作り、各格子点で洗浄前後のコントラスト差を直接計算する。各ずれ条件で空白試料から基準しきい値を再計算し、視野ごとのしきい値超過率に対して正確な両側マン・ホイットニー検定を行った。位置合わせ処理、格子生成、濃度統計の既定動作は変更していない。

ずれ量は0.05、0.1、0.2、0.5、1.0 px。系統ずれは全視野・全格子点へ同じ+x方向の移動、ランダムずれは視野ごとに再現可能な乱数方向を決め、その視野の格子点すべてへ同じ大きさ・方向の移動を与えた。したがって「ランダム」はピラーごとに独立した揺らぎではなく、視野単位で方向が異なる並進である。

v16の現行品質判定を通過し、高濃度群と空白群の両方があり検定できる7データセットの366組を対象とした。260829 DNAは高濃度群が0視野で、検定不能のため除いた。ずれ0 pxの再計算p値は7データセット全てでv16報告値と一致し、同じ対象集団・統計手順を再現できていることを確認した。

## 結果

70個のずれ条件（7データセット×2方向×5ずれ量）で、p値が0.05以下になった条件はなく、元の「濃度差は有意でない」という結論が反転した条件もなかった。試した範囲内では、結論は1.0 pxまで維持された。ただし、1.0 pxのランダム方向では260827 DNAのp値が0.3357から **0.0721** まで下がり、0.05に近づいた。系統+xの同データセットでは最低p値0.1206だった。

|---:|---:|---:|---:|---:|
| 0.05 px | 0.0108 | 0.00001 | 0.000024 | 0.000024 |
| 0.1 px | 0.0354 | 0.0278 | 0.000039 | 0.000035 |
| 0.2 px | 0.0583 | 0.0518 | 0.000061 | 0.000062 |
| 0.5 px | 0.0855 | 0.0833 | 0.000120 | 0.000124 |
| 1.0 px | 0.1062 | 0.1023 | 0.000223 | 0.000241 |

コントラスト変化は、画像を65535で割った正規化強度の差で、ピクセル位置の単位ではない。現行標本器が座標を整数画素へ丸めるため、ずれが0.05〜0.2 pxの範囲では、視野内の多くのピラーの標本座標が変わらず、ピラーごとの中央値変化は0になる。これも本番経路の実際の量子化を含んだ結果である。高いずれ量ではコントラスト変化が増え、特に1 pxで分布裾の変化が見られるが、視野平均や検定の結論はこの試験範囲では保たれた。

濃度統計のデータセット別p値・検定統計量は `position_error_dataset_tests.csv` に全条件を記録した。p値の最小値は、1.0 px・ランダム方向の260827 DNAにおける0.0721。基準p値と全条件の変化を含む。

## 位置誤差の目標とA段階との照合

この試験だけから統計的結論が変わる境界は見つからず、少なくともここで試した平行移動は1.0 pxまで有意差の結論を変えなかった。したがって「1 pxを超えても安全」とは言えない。1.0 pxで最小p値が0.05に近づいたため、運用目標としては余裕を取り **0.5 px以下** を保守的な目標とするのが妥当と考える。これは検証で特定された厳密な閾値ではなく、今回の試験点とp値変化から置く暫定的な目標である。

A段階の独立中心残差では、401視野の視野ごとの残差中央値を集約した値が0.602 px、視野内残差95パーセンタイルの視野間中央値が1.852 pxだった。前者は暫定目標0.5 pxを少し上回り、後者はさらに大きい。ただしAの残差には洗浄前後の中心形状・コントラスト・焦点の変化が含まれ、幾何位置誤差だけではない。よって現行位置合わせが目標を満たしていないと断定はできないが、独立中心の観測上は0.5 px以下を全視野で達成したとは確認できていない。外れ視野の調査は引き続き必要。

## 限界

この実験は洗浄後標本座標へ既知の一様な平行移動を追加した感度評価であり、回転・倍率・視野内の非アフィン変形、ピラーごとに異なる位置誤差、位置誤差と欠陥マスクの相互作用は試していない。ランダム方向も視野ごとの一様な移動である。また、7データセット中の260826 SAMは空白視野が1件と少なく、正確検定のp値は粗い離散値となる。したがって、ここでの「1 pxまで結論維持」は、この実験条件での結果であって一般保証ではない。
