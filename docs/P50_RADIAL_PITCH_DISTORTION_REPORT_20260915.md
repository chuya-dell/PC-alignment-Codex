# p50 視野内ピッチ均一性（放射歪み）検証 — 2026-09-15

## 結論

既存の高濃度 p50 pre画像 11視野（5日程、SAM/DNA、複数FOV）を用いた今回の検証では、
**全FOVに共通する単調な放射歪み、およびそれを表す再現可能な Brown `k1, k2` は確認できなかった。**
したがって、確定済みのグローバル格子ピッチ `a=7.286 px`（460 nm、63.14 nm/px）を
空間依存の値に置き換える根拠はない。現行のグローバルFFT格子生成・投影を維持する。

局所FFTの「角4タイル平均 − 中心タイル」は −0.70%〜+0.84%（11視野、中央値 −0.42%、
平均 −0.20%、SD 0.46%）で符号が一定しなかった。確定済みの `a` に対するこの診断上の
最大局所差は 0.061 px（約3.8 nm）/pitch に相当するが、日程・FOVを横断した校正値ではない。
よって端部へ歪み補正を導入したり、`a` を再推定したりしない。保守的には、端部の局所格子を
扱う将来の診断で ±0.84% を「今回観測したFOV間のばらつき上限」として監視する。

## 対象画像と選定

`data/raw/p50_radial_distortion_manifest.json` のSample 1を全FOVスクリーニングし、
既存 `shared.analyzer.analyze_image` の有効な最近接検出数を優先して選んだ。
260827は既存台帳どおり1 nMのSample 12である。

新しい検出器は作らず、既存ロジックを流用した。

`analyze_image(method="peak", min_dist=3, threshold=0.2)` は、トップハット背景補正、
局所極大、3×3強度重み付き重心を行う。従って出力座標はサブピクセル座標である。

## 方法

1. 画像サイズ2048×2044の幾何中心 **(1023.5, 1021.5) px** を使った。このリポジトリには
   光軸中心の独立キャリブレーションは登録されていない。
2. 各検出点にKDTreeで最近接点を付け、5.5–9.0 pxの点だけをピッチ診断用に残した。
   半径を 0–200, 200–400, …, 1000+ px にビニングし、平均・SD・SEMを保存した。
3. 画像を5×5タイルにし、既存 `estimate_hex_orientation_fft` による全体方位に沿った
   6本の第一逆格子ベクトルを、4倍ゼロパディングFFTで測定した。中心タイルと4隅の
   平均を比較した。方位を拘束するため、端部の非格子ストリークを格子ピークと誤認しない。
4. 最近接法とFFT法がともに所定の効果量（各0.10%, 0.05%）を超え、かつ同符号の時だけ、
   固定 `a=7.286 px` 格子への割当点を用いて Brown
   `r_distorted = r_ideal(1 + k1 r_ideal^2 + k2 r_ideal^4)` をロバストフィットした。
   これは既定ピッチの再推定ではない。

各FOVの散布図は `data/results/v2_radial_pitch_distortion/<FOV>/radial_pitch.png`、
点群・半径ビン・FFT・Brown結果は同フォルダのCSV/JSONに監査可能な形で保存した。

| 260824 SAM S1 P5 | −1.73% | −0.70% | はい |
| 260825 DNA S1 P3 | −3.28% | −0.55% | はい |
| 260826 SAM S1 P3 | −2.96% | −0.57% | はい |
| 260826 SAM S1 P5 | −3.74% | −0.45% | はい |
| 260826 SAM S1 P6 | −2.71% | +0.23% | **いいえ** |
| 260826 SAM S1 P8 | −3.17% | −0.13% | はい |
| 260827 DNA S12 P3 | +0.87% | +0.84% | はい |
| 260827 DNA S12 P5 | +0.37% | −0.49% | **いいえ** |
| 260828 SAM S1 P4 | −1.52% | +0.16% | **いいえ** |
| 260828 DNA S1 P8 | +0.39% | −0.12% | **いいえ** |
| 260829 SAM S1 P4 | −0.09% | −0.42% | 効果量未満/いいえ |

無拘束局所極大の最近接値は日程ごとに約6.4–6.9 pxであり、確定済みFFTピッチ7.286 pxの
絶対的な再測定には使えない。一方、同一画像内の半径方向のQCとしては有用である。
外周で短くなる傾向が多く見えるが、FFTは260827 P3で増加、260826 P6で増加、他でも
符号反転した。従ってこの最近接の共通傾向は、端部でのピーク選択・検出率の変化を含む可能性が高く、
光学的ピッチ変化の証拠とは扱わない。

Brown fitが実行された6視野でも `k1` の符号・大きさは一致しなかった。
特に260827 P3では測定された+0.84%に対し、フィットの1000 px予測は−0.032%である。
260826 P8だけは残差が 1.69→1.37 px と減少したが、1000 px予測−0.124%は他視野で再現せず、
単独FOVの補正係数として採用しない。

## 既知の収束不良との整合性

- **FOV 1-6**: 260826 Sample 1 Position 6 は局所FFTで角−中心が **+0.23%**、
  最近接値は−2.71%であり、独立指標が一致しなかった。Brown fitの採用条件も満たさない。
  このFOVを、視野周辺で一方向に累積する放射歪みが局所解トラップを作った事例として説明することはできない。
- **260827位置3・5**: 両方が過去にICP非収束だったにもかかわらず、位置3は+0.84%、
  位置5は−0.49%（局所FFT）で逆向きだった。共通の対物レンズ放射歪みなら同じ符号・類似係数を
  期待するが、観測はそうならない。

従って、今回の観測は「レンズ歪みがこれらの収束不良の主因」という仮説とは整合しない。
より整合的な次の確認対象は、各FOVのピーク検出品質、初期位相/向き、対応点の外れ値、ICPの
初期化・局所解である。ただし、端部の局所格子差を完全にゼロと証明したものではないため、
将来の独立キャリブレーション格子または光軸中心測定が得られれば、同じ解析の中心座標だけを
置換して再実行する。
