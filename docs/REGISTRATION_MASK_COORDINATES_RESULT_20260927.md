# Pre/postシミマスクの座標整合と再計測 — 2026-09-27

## 実装

stain maskを有効にした場合、pre・postの候補マスクをそれぞれの生画像座標で独立検出する。先に明部帯
など既存マスクだけで粗アフィンを推定し、そのpre-to-post行列でpostマスクをpre座標へ写してからORする。
共通preマスクは同じ変換でpost座標へ戻し、ORBにはpre/postそれぞれの座標に合った除外マスクを渡す。
ORB経路は再推定後にマスク位置も更新し、最大3回の再フィットまたは行列変化1e-4未満で終了する。
ECC経路は同じ座標写像後にpost座標のマスクを使って再推定する。

座標テストはpostだけに付着した点とpreだけに残る点を配置し、平行移動後に両方が対応する物理点で
除外され、反対側の未対応ピクセルへ漏れないことを検証する。既定経路は変えず、mask_stains=False
では既存の単一除外マスクを一度だけ使う。stain_artifact_mask本体、格子拘束、反復最適化、
測光値サンプリング処理は変更していない。

## 452条件の既知変換ベンチマーク

前回と同じ生画像、452の真値変換、RMSE定義を使用した。各段階452/452件が完了し、例外による失敗は0件。

座標整合により最悪値は6.108pxから3.895pxへ下がったが、1px以上の条件は6から8へ増加した。
前回の未整合マスクとのペア比較では、新マスクが改善198・悪化221・不変33条件。通常サブピクセルに
対する新マスク＋サブピクセルは改善179・悪化243・不変30条件で、中央値・95%点・1px以上の件数も
通常サブピクセルより悪い。よって座標修正は実装上の不整合を直したが、マスクを一律適用する有効性は
確認できず、マスクは引き続きオプトインのままとする。

### SAM pos6 axis14

同一条件のRMSEは通常サブピクセル0.03035px、前回未整合マスク6.108px、座標整合マスク1.8265px。
座標整合マスク付きサブピクセルも1.8265pxで、更新されなかった。トラック数は690から1,171へ増え、
held-out誤差中央値は0.3213pxから0.08465pxへ改善したが、更新候補は粗変換から視野内最大3.227px
動くため、同一格子セル内に留める上限（7.286/4=1.822px）を超え、安全ガードで棄却された。
座標ずれを直した結果、マスクで特徴点支持が失われる症状は軽減した一方、初期粗変換が誤っている
条件はセル飛び防止ガードを越えられず救済できていない。今回、同ガード自体は変更していない。
