# 半合成位置合わせ精度: 基準値とサブピクセル段階

## 条件

既知のpre→postアフィン変換を実画像に適用し、既存の`register_image_pair_affine`
（ORBF特徴点/RANSAC、明部帯マスク）で復元した。824〜829の実変位・回転・倍率の範囲を
含む452条件、画像27枚を評価した。中心位置、回転による視野端の変位、倍率による視野端の
変位、視野内81点のRMSEを記録した。同一の入力、変換、シードを全段階で使用する。
変換の向きは後段の格子サンプリングと同じpre→postであることを、独立した既知変換試験で
確認した。0変換条件27件を含めた平均・分位値と、除いた425件の平均・分位値を分けて保存した。

## 結果

| 指標 | 基準: 中央値 / 95%点 / 最大 | サブピクセル: 中央値 / 95%点 / 最大 |
|---|---:|---:|
| 中心位置誤差 (px) | 0.0555 / 0.2581 / 5.4414 | 0.00169 / 0.00853 / 5.4414 |
| 回転誤差の視野端換算 (px) | 0.0378 / 0.2214 / 2.2843 | 0.00180 / 0.01126 / 2.2843 |
| 倍率誤差の視野端換算 (px) | 0.0360 / 0.2601 / 4.2464 | 0.00219 / 0.01352 / 4.2464 |
| 視野内位置RMSE (px) | 0.08935 / 0.36425 / 6.8291 | 0.00401 / 0.01589 / 6.8291 |

視野内位置RMSEは452条件中420件で改善、32件で不変、悪化0件。最大誤差は不変である。
この大きな誤差群は初期変換が誤った格子セルを選んだ例で、サブピクセル段階の変位上限を
1/4ピッチに設定したため救済しない。続く格子段階では、この問題を隣接する格子セルへの誤
対応を防ぐ設計と併せて評価する。
段階間の初期値の揺れを除くため、保存済み基準変換をそのまま各精緻化段階に渡して再計測した。
表とCSVはこの固定初期値の再計測結果を示す。最初の再計測は特徴点推定も段階ごとに再実行して
いたため、Git履歴には残すが精度比較の正式結果には使わない。

## 実データの基準再計測

既存の409組を同じ位置合わせ・解析経路で再実行した。399組が採用、10組がQC棄却となり、
保存済みマスク適用解析とデータセット別のexact Mann–Whitney p値が全て一致した。
260825 DNAのp=0.128205、他の判定可能な主要5検定もp>0.05である。260826 SAMはblank数が1、
260829 DNAは比較対象のSample 1がないため、これら2件から濃度依存性を結論しない。
399組の共通支持領域における高周波photometric residualの中央値は0.5235、独立タイルの
局所位相ずれ中央値は4.470 pxだった。いずれも実画像の残差指標であり、絶対誤差ではない。

この時点の画素残差は、局所位相相関と高周波画像相関の指標であり、実画像には既知の物理
位置正解がない。改良版と同じ共通画素・タイル上で比較し、絶対幾何誤差とは区別する。

## FFT格子段階

前段階の結果行列を直接入力にし、pre画像のピッチ7.286 pxの六方FFT格子を使って、
格子中心近傍13点のコントラストパターンを整列する相似変換を1回だけ更新した。
マスク接触領域を除き、画像の空間範囲で分けた80%の格子点で更新し、残り20%でも
コントラスト損失が増えない場合だけ採用した。隣の格子セルへの移動は禁止した。

| 視野内RMSE | サブピクセル | FFT格子 |
|---|---:|---:|
| 中央値 (px) | 0.00401 | 0.00517 |
| 95%点 (px) | 0.01589 | 0.02346 |
| 最大 (px) | 6.8291 | 6.7614 |

452条件中180件は改善、204件は悪化、68件は不変。平均RMSEの差はわずかに減る方向
（−0.00021 px）だが、中央値と95%点は悪化した。検証格子点のコントラスト損失低下だけでは
真の位置精度向上を保証できないことを確認した。したがって、この評価では格子段階を
サブピクセル段階より優れると判定しない。

実データのサブピクセル段階399件では、高周波photometric residualが151件で低下、
26件で上昇、222件で不変（中央値差0、平均差−0.0112）。局所位相ずれは96件で低下、
81件で上昇、222件で不変（中央値差0、平均差−0.0094 px）。改善は平均指標に限られ、
変化の中央値はどちらも0。これらは画像一貫性の代理指標であり、真の位置誤差の低下を
示す証拠ではない。

## 反復段階

一段階の格子更新結果を初期値として、検証用格子点の損失が改善する更新だけを繰り返した。
452条件中87件で改善、11件で悪化、354件は不変。一段階の格子更新に対する視野内RMSEは
中央値0.00517→0.00503 px、95%点0.02346→0.02340 pxと、ごく小さく下がった。
サブピクセル段階の中央値0.00401 px、95%点0.01589 pxには及ばない。
今回の既知変換評価では、固定格子+反復がサブピクセル法をさらに上回る証拠は得られなかった。
更新回数は102条件で1回64、2回21、3回10、4回5、5回2。残る350条件は追加の
検証安全な更新がなかった。

## 実データのFFT格子段階

399件採用、10件QC棄却の構成は基準と同じ。高周波photometric residualは323件で低下、
70件で上昇、6件が不変（中央値差−0.00288、平均差−0.02171）。局所位相ずれは229件で低下、
164件で上昇、6件が不変（中央値差−0.00627 px、平均差+0.00535 px）。画像相関の改善は
見られるが、位相ずれの平均はわずかに悪化し、実データの幾何精度に一様な改善はない。

濃度比較は、260824 SHC6OH p=0.949717、260825 DNA p=0.097319、260826 SAM p=1.0、
260827 DNA p=0.463403、260828 DNA p=0.778866、260828 SAM p=0.832945、260829 SAM p=0.694328。
検定可能な6件すべてp>0.05で、濃度依存性なしという結論は変わらない。
