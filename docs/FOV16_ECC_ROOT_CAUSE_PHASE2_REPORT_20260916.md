# FOV 1-6 ECC局所解トラップ診断（Phase 2）— 2026-09-16

## 結論

判定は **(c) 現時点では原因を一意に説明できない** とする。

独立実装した生画像・アフィンECCでは、FOV 1-6の0.125→0.25→0.5→1.0ピラミッドと
初期並進25通り（x/y = −10, −5, 0, +5, +10 px）の全経路が同一解へ収束した。
最良 `rho=0.986606`、最小 `rho=0.986602` で、`rho>=0.978` の解は存在する。
ただし標準の0.25→0.5→1.0・ゼロ開始も `rho=0.986602` でほぼ同一の変換へ収束したため、
**深い初期化や初期並進グリッドが新しい大域解を見つけたわけではない。**

また、このリポジトリには2026-09-01のECC実装・前処理・変換モデルが保存されておらず、
既知の `rho=0.971`, `Delta s=-0.239%`, `theta=-0.026 deg` を厳密に再現する実行経路はない。
今回の数値を既存パイプラインの置換根拠にはできないため、デフォルト変更は行わない。

## 対象と実装

- 対象: 260826 p50 SAM、Sample 1、FOV 1-6。比較用にFOV 1-1と1-5。
- 実装: `field_level/v3_fov16_ecc_root_cause/field_diagnose_fov16_ecc.py`
- 再利用: `shared.analyzer.analyze_image`（サブピクセル局所極大）と
  `shared.lattice_indexing.estimate_hex_orientation_fft`。
- ECC入力: 16-bit画像を `0..1` へ正規化した生画像。高域強調は既知ECC結果との比較を
  妨げるため採用しなかった。
- 格子ピッチ: 確定済み `a=7.286 px` を固定し、再推定していない。

## 1. 深いピラミッド・初期値グリッド

| 条件 | rho | tx (px) | ty (px) | theta (deg) | Delta s |
| --- | ---: | ---: | ---: | ---: | ---: |
| 4段最良（初期 −5, +10 px） | 0.986606 | −15.90549 | +4.76174 | −0.00512 | +0.02577% |
| 3段・ゼロ開始 | 0.986602 | −15.90555 | +4.76185 | −0.00512 | +0.02577% |

25/25経路が収束し、最終rhoの幅は `3.94e-6`、txの幅は `0.000070 px`、tyの幅は
`0.000123 px`、thetaの幅は `0.0000040 deg` だった。少なくとも今回の独立ECC目的関数の
±10 px範囲には複数の競合する局所解は見えない。

この結果は閾値 `rho>=0.978` を満たすが、標準3段でも同値である。従って「0.125開始を
デフォルトへ変更する」根拠にはならない。

## 2. ピーク検出・対応点品質

既存検出器のFFT格子1.5 px内ユニークセル率は、FOV 1-6 pre/postで14.36% / 13.88%、
比較FOV 1-1で14.11% / 14.66%、FOV 1-5で14.00% / 13.97%だった。FOV 1-6だけが
低下しているとはいえない。

この絶対率は検出器が無拘束の局所極大を返すことによる診断値で、物理的なピラー検出率ではない。
また、現行 `analyzer` は近接ピークを事前にpruneするため、出力上の二重ピーク率0%は
「二重ピークが物理的に無い」ことを意味しない。二重ピークを除外基準に使うには、prune前候補を
保存する別の検出QCが必要である。

FOV 1-6のpost→pre対応点は画像周縁で悪化した。例えば8×8タイルの左下側では一致率
0.13–0.16、中央値残差約3.4 px、95パーセンタイル8.5–9.4 pxだった。一方で視野中心部は
一致率が高く、残差も低い。この境界悪化はFOV 1-5にも近い全体一致率（FOV 1-6: 79.7%,
FOV 1-5: 76.4%）があるため、FOV 1-6固有の原因とは断定できない。

## 3. FFT方位

FOV 1-6の全体FFT方位はpre 17.782 deg、post 16.902 deg、差+0.880 degだった。
タイルbootstrap SDはpre 3.74 deg、post 2.80 deg、第一逆格子ピークSNRは8.38 / 8.28。
比較FOV 1-1のSD 3.75 / 3.05 deg・SNR 8.67 / 8.65、FOV 1-5のSD 2.96 / 3.08 deg・
SNR 8.42 / 8.58と比べ、FOV 1-6にだけFFTピーク崩壊はない。

ただしタイル間の方位ばらつきが数度あり、既知の物理回転差0.011–0.026 degをこの簡便FFT推定で
精密に評価することはできない。FFT方位は初期化用の粗い指標に留める。

## 4. フォーカス

Laplacian分散（pre/post）はFOV 1-6で0.001343 / 0.001394、FOV 1-1で0.001334 / 0.001386、
FOV 1-5で0.001340 / 0.001394だった。TenengradもFOV 1-6が0.00712 / 0.00833で、
比較2視野より低くない。FOV 1-6だけの明確なデフォーカスは支持されない。

## 総合判断と次候補

画質、粗いFFT方位、既存ピーク検出率、焦点指標にFOV 1-6だけの決定的悪化は見つからなかった。
一方で、元の2026-09-01 ECC経路がこのリポジトリにないため、当時の `rho=0.971` の局所解仮説を
直接肯定・否定することもできない。

次の調査は以下の順に行う。

1. 2026-09-01で使ったECCの**前処理、変換モデル、マスク、収束条件**を一次記録から固定し、
   このリポジトリ内に再現スクリプトとして保存する。
2. `analyzer` のprune前ピーク候補を保存し、二重ピーク・欠落を格子セル単位で評価する。
3. 既知のFOV 1-6境界残差に対し、傷・シミ・十字傷の承認済み座標が得られた場合だけ、
   その領域をマスクしたECC再試行を行う。
