# 独立検出中心からのアフィン再推定による精度上限の事前検証

**この報告では、半合成画像の「既知の変換に対する絶対誤差」と、画像内で対応中心が示す「残差指標」を区別する。** 前者は与えた正解変換との差を直接測る。後者は洗浄前後の形状、明るさ、焦点の変化や中心検出の誤差も含むため、真の位置誤差そのものではない。

## 結果

半合成452条件を、v17と同じ独立中心検出法で再評価した。中心対応からのアフィン再推定は、既知変換に対する絶対誤差で現行標準より悪かった。視野内二乗平均平方根誤差の中央値は、現行標準が **0.00392ピクセル**、再推定が **0.00843ピクセル** だった。差の中央値（再推定から現行標準を引いた値）は **+0.00405ピクセル** で、95パーセンタイルは **+0.02804ピクセル** だった。

452条件のうち、再推定の誤差が現行標準より0.000001ピクセルを超えて小さかった条件は114、同じ幅以内だった条件は27、大きかった条件は311だった。現行標準の誤差中央値は、従来の半合成評価で報告した約0.0040ピクセルと一致する。

| 指標 | 現行標準 | 中心から再推定 |
|---|---:|---:|
| 既知変換との差：中央値 | 0.00392 px | 0.00843 px |
| 既知変換との差：95パーセンタイル | 0.01430 px | 0.03350 px |
| 既知変換との差：最大 | 0.06280 px | 0.05046 px |
| 空間ブロック外の対応中心残差：中央値 | 0.43739 px | 0.43715 px |

空間ブロック外残差の視野単位差の中央値はほぼ0ピクセルで、残差中央値の差も約−0.00024ピクセルにとどまった。これは画像内の対応中心残差という代理指標であり、既知変換に対する絶対誤差の悪化とは別の量である。したがって、この小さな差を精度向上とは解釈しない。

再推定は450条件で収束し、2条件は最大10回の対応再割り当てまでに収束しなかった（260828 SAM sample1 pos6、260827 DNA sample1 pos6）。条件ごとの反復回数の中央値は4回だった。再割り当てで変わった対応の累積数の中央値は22件だった。変更割合は、累積変更数を「対応数×（反復回数−1）」で割った推定値で、中央値0.022%、95パーセンタイル0.071%である。各反復で対応数がわずかに変動し得るため、割合は近似値として扱う。

## 方法

半合成の452条件、元画像27枚を使用した。各画像のピラー中心は、v17で使った独立検出器で画像ごとに検出した。信頼度が中央値以上の中心について、現在の変換による予測位置から最も近い中心を一対一で割り当て、公称格子ピッチ7.286ピクセルの半分以内にある対応だけで初期の再推定を行った。

アフィン変換は外れ値の影響を抑える反復重み付き最小二乗法で推定した。変換を更新した後に対応を割り当て直し、最大10回まで繰り返した。対応の並びが変わらず、視野全体での変換位置差が0.0001ピクセル未満になった時点を収束とした。各フィットの反復上限は30回、重み付けにはHuber損失を用い、尺度の下限を0.12ピクセルとした。

過剰適合の確認では、視野を4行×4列の空間ブロックに分け、各ブロックを順に評価対象として除外し、残りのブロックで推定した変換を除外ブロックの中心で評価した。評価する中心対応は現在の変換で作った一対一対応を固定した。このため空間ブロック外残差は補助指標とし、既知変換との差を最終判定に用いた。

## 解釈と範囲

本手法は半合成の絶対誤差で現行標準を上回らなかった。よって、実データ401組で同じ再推定を行っても、得られる残差を位置合わせの改善上限として解釈できる根拠がない。依頼の判定条件に従い、実データの変換パラメータ差、中心・四隅の位置差、実データの空間ブロック外残差、個別視野のベクトル図と残差マップは算出していない。

今回の結果から言えるのは、現行変換を初期値にした中心再推定が、今回の半合成条件では既知変換の再現を改善しなかったことまでである。実データの残差のうち変換誤差が占める割合や、位置合わせの改善余地の上限は未確定である。悪化の候補には、独立検出中心の局所的な形状依存、明るさ差、焦点差、初期変換で決めた対応への依存があるが、今回の測定だけでは原因を特定できない（原因判断の確度：低）。半合成で標準より悪かったという判定の確度は高い。

位置合わせの標準経路、既定動作、各オプションおよび整数画素への丸めを行う標本器は変更していない。
